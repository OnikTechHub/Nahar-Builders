# Nahar's Builders

> **Tagline:** *"Building Trust, Engineering Excellence"*

A modern, original, high-end real estate and civil engineering web application frontend built with **Next.js (App Router)**, **TypeScript**, and **Tailwind CSS on a clean white theme (`#FFFFFF` / `#F8FAFC`)**.

---

## Key Features

- **Clean White Corporate Theme:** Pure white (`#FFFFFF`) with subtle soft surface sections (`#F8FAFC`), crisp dark charcoal typography (`#111827`, `#1E293B`), and architectural crimson red accents.
- **Logo Integration:** Seamless integration of Nahar's Builders logo served reliably from `/public/nahar-builders-logo.jpg`.
- **Reusable Sticky Navbar:** Multi-level dropdowns for *About Us*, *Services*, and *Projects*, plus quick hotline bar, mobile drawer, and quick consultation modal.
- **Interactive Home Page:**
  - Modern bright architectural hero section with dual CTAs and floating key stats cards.
  - About Nahar's Builders section with 25+ years experience badge and 4 core engineering pillars.
  - 4-card core services grid with interactive feature checklists.
  - Filterable developments showcase (*All*, *Ongoing*, *Completed*, *Upcoming*).
  - Construction excellence and BNBC 2020 seismic safety benchmark callouts.
  - Client reputation & testimonial reviews.
  - Quick consultation and site visit booking banner.
- **Full Route Architecture:** Dedicated routes for `/about`, `/services`, `/projects`, `/gallery`, and `/contact`.
- **API-Ready Data Layer:** All data modularized in typed files under `src/data/` for straightforward integration with a backend REST API.

---

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
```
